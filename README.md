# MATH261B Project
Project repository for MATH 261B Experimental Design at SJSU.

SUMMARY SENTENCES SPECIFIC TO OUR PROJECT

## Data 

Data used in this project is obtained from the GLDreg R library as the ACTG320 dataset. Specfic reference is noted in the bibliography.

## External Resources

The final report and code were written by Susan Peck, Jan Blackburn, and Joseph Burks. The key documents listed below can be accessed in the Document_Files subfolder.

To report was created using quarto files and to facilitate collaboration, a parent-child file organization was used.  The files and purpose are as follows:
- Math261B_Final_Paper_v1.qmd: This is parent document that should be used to render the document.
- Child_Introduction_v1.qmd: Introduction section
- Child_LitReview_v1.qmd: Literature review of key studies that framed the research question for the paper.
- Child_Study_Design_v1.qmd: Summarizes the ACTG320 study design and key statistics
- Child_Methods_v1.qmd: Explains key concepts and statistical tools for survival analysis that were applied in the paper
- Child_Results_v1.qmd: Key file in which most of the analysis is performed and associated results discussed.
- Child_Discussion_v1.qmd: Discussion and conclusions section
- Appendix_Tables.qmd: Includes additional tables that were moved to an appendix. Note that this file is not stand alone and can only be generated by rendering the full document.
